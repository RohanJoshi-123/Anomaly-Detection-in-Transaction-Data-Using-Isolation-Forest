# Anomaly-Detection-in-Transaction-Data-Using-Isolation-Forest

## 📌 Project Title
Anomaly Detection in Financial Transactions

## 📖 Domain
Data Science / Machine Learning

## 🎯 Objective
The objective of this project is to detect unusual or suspicious transactions using anomaly detection techniques.  
The system helps identify transactions that do not follow normal patterns.

## 🗂️ Dataset Description
The dataset contains financial transaction records.  
It includes features such as transaction amount, transaction type, and other related attributes used to analyze abnormal behavior.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 🔎 Project Workflow

1. Data Loading  
2. Data Cleaning  
3. Exploratory Data Analysis (EDA)  
4. Feature Selection  
5. Applying Anomaly Detection Model  
6. Identifying Outliers  
7. Visualizing Results  

## 🤖 Machine Learning Model Used
- Isolation Forest (for detecting anomalies)

## 📊 Results
- Successfully identified abnormal transactions
- Visualized normal vs anomalous data points
- Understood how anomaly detection works in real-world datasets

## 💡 Learning Outcomes
- Gained hands-on experience with anomaly detection
- Learned how to preprocess real-world data
- Improved understanding of unsupervised learning techniques

## 📌 Conclusion
This project demonstrates how Machine Learning can be used to detect unusual transaction patterns.  
It provides a basic understanding of fraud detection using anomaly detection models.
